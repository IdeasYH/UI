# SearchSelect：平铺选项中的单值选择

先按 [通用复用方法](../UI-REUSE.md) 判断数据结构。只要需求是“从一组平铺选项确认一个稳定值”，就可以比较本组件，不限于演示中的套餐或城市。少量选项需要并列比较时看 RadioCards；多选、树或路径选择分别比较 CheckboxCards、TreeSelect、Cascader。

网站入口：`/components?category=interaction#search-select`。真实调用示例：[search-select-example.tsx](../../src/examples/search-select-example.tsx)。网站展示该文件，本文不另复制一份代码。

## 输入与输出

| 参数 | 类型和含义 | 调用方约束 |
| --- | --- | --- |
| `label` | `string`，可见字段名和无障碍名称 | 说明正在选择什么 |
| `options` | `readonly SelectOption[]`，本地选项 | `value` 唯一且稳定；不要使用可能改名的标签作为长期 ID |
| `value` | `string`，已确认值 | 没有选择时可传空字符串；选项更新后的失效值由宿主处理 |
| `onChange` | 接收选中 `value` 的回调 | 更新宿主持有的值；组件不保存业务数据 |

`SelectOption` 包含 `value`、`label`，可选 `pinyin`、`initials`。搜索匹配标签、拼音和首字母的连续片段，忽略大小写和查询两端空白；它不自动生成拼音，也不按 ID 搜索。拼音缺失时仍可按标签搜索。

## 状态与确认时机

| 操作 | 当前行为 | 是否调用 `onChange` |
| --- | --- | --- |
| 打开或关闭触发按钮 | 切换展开状态，清空搜索，活动候选回到开头 | 否 |
| 输入搜索 | 本地过滤，活动候选回到过滤结果开头 | 否 |
| 点击候选或确认活动候选 | 提交候选 ID、关闭、清空搜索、焦点回触发按钮 | 是 |
| 搜索无结果 | 显示空态，保留原已确认值 | 否 |
| Escape | 关闭并清空搜索，焦点回触发按钮 | 否 |
| 焦点离开整个控件 | 关闭并清空搜索 | 否 |

总选项数量大于五项时才显示搜索输入，不按过滤后的结果数量决定。少于或等于五项时直接列出候选。当前没有清空选择按钮；宿主若提供重置操作，需要更新 `value`。

`value` 是受控值，外部更新后标签与勾选随 props 渲染。如果值已不在 `options` 中，触发按钮显示“请选择”，组件不会自动修改宿主值；宿主必须决定清空、保留历史标签或提示失效。重复点击已选项仍会调用回调，调用方不要把每次回调都视为必然发生了业务变更。

## 为什么这样设计

选中值与临时搜索分开，用户可以探索候选而不丢失已经确认的选择。保存稳定 ID、展示标签，使改名不改变业务关联。小选项集直接展示以减少输入步骤，超过五项搜索是当前实现阈值，不是适用于所有场景的行业规则。

## 迁移到未列举业务

1. 确认目标保存一个值且选项平铺；如果值实际是一组 ID 或一条路径，先换原型。完成条件：值形状一致。
2. 将数据源映射为稳定 `value` 与用户可读 `label`；确有拼音数据再填搜索字段。完成条件：ID 唯一、标签正确、未知字段没有伪造。
3. 把宿主已有状态接到 `value/onChange`，明确重置和选项失效时的处理。完成条件：选择、外部重置和数据刷新都能解释。
4. 根据容器适配样式，验证过滤、焦点和空结果；再接入宿主保存或查询。完成条件：临时输入没有触发错误的业务提交。

| 业务映射示例 | 保持的结构 | 宿主替换内容 |
| --- | --- | --- |
| 选择一个出库仓库 | 平铺候选 → 一个仓库 ID → 选择即确认 | 仓库列表、名称、可用范围及失效仓库处理 |
| 选择一个工单模板 | 平铺候选 → 一个模板 ID → 选择即确认 | 模板列表、标题、搜索字段和后续内容加载 |

这两例用于说明映射步骤。设备、资源、渠道等未列举对象也按同一结构判断，不需要先把业务名称加入目录。

## 必须保留、可以调整、宿主负责

| 层次 | 约定 |
| --- | --- |
| 必须保留 | 单值语义、稳定 ID、搜索不提交、选中标记、空结果不破坏已选值、可见焦点与标签关联 |
| 可以调整 | 选项、字段名、外层布局及有作用域的颜色/尺寸；搜索阈值和固定提示目前不是 props，修改需同步契约 |
| 宿主负责 | 数据加载、权限过滤、选项失效处理、保存/查询、错误反馈、清空业务值 |

蓝色高亮和勾号区分“已选”，浅底表示鼠标或键盘活动候选。颜色可以适配目标系统，但不能让活动候选看起来已经提交。浮层在控件内绝对定位，需检查祖先 `overflow`、页面滚动和遮挡；当前不提供 Portal 或碰撞避让。

## 键盘及尚未支持的能力

触发按钮支持原生 Tab、Enter 和空格。搜索框出现后自动聚焦；在搜索框中用上下方向键移动活动候选，Enter 确认，Escape 关闭。列表候选可用 Tab 访问并通过原生按钮激活。没有搜索框时按 Tab 选择候选；当前未实现触发按钮直接方向键展开或完整 listbox 漫游焦点协议。

当前未提供多选、远程搜索、分页、虚拟滚动、加载/请求失败状态、整控件禁用、单项禁用、自动拼音和创建新选项。需要这些能力时先确认新契约，不能只把远程接口放进本地过滤函数。大量数据是否适合当前列表应在目标场景实测。
