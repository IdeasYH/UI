# LiquidGlass 液态玻璃光影面板

ID：`liquid-glass`。独立页面：`/examples/liquid-glass`。根据用户提供的静态图片重建，非原作者源码；图片没有提供时间轴，流光与鼠标响应为本项目补充设计，不宣称与未知原版动效完全一致。

## 选择与泛化

适用于需要半透明、厚边缘、折射色与空间投影的展示面板。图中工作区只是演示：同样材质可以用于工具面板、媒体控制或设置界面，具体对象名称不是使用白名单。先选定真实交互（布尔、多值、互斥单值或提交），再应用材质；玻璃外观不能代替这些状态规则。

## 接口与真实示例

`LiquidGlass({ title?: string })` 渲染完整材质展示，默认标题为 Liquid Glass。调用示例见 `src/examples/liquid-glass-example.tsx`。当前是页面组合，不是独立业务表单库。

- 两个复选框独立切换；第一个和圆环共享同一个确认状态。
- 开关保存即时布尔值，滑块位置表示开关状态；它不控制整页动画。
- 分段控件互斥选择 Grid / List，仅展示选中状态，不承诺切换未实现的列表。
- 输入框可输入，创建工作区要求非空，操作反馈明确为本地演示；没有真实创建、搜索服务、邀请、升级购买或持久化。
- Reset 重置搜索、共享确认、开关与分段状态；独立的 Auto fit 和工作区输入不属于此重置范围。

宿主接入时应把需要保存的状态提升到调用方，并替换演示消息为实际回调。不要把显示反馈视为服务端成功。

## 光影与样式边界

复制 TSX 与同目录 CSS，需要 React/React DOM 和支持 CSS 导入的构建工具，无新增依赖。所有样式限定在 `lg-` 前缀。背景是玻璃观感的一部分，换背景后需重新检查可读性。

`--light-x`、`--light-y` 控制高光位置，`--shadow-x` 控制投影水平偏移。指针离开后恢复默认；指针更新直接设置 CSS 变量，不触发 React 高频渲染。多层渐变、内阴影及 backdrop-filter 模拟折射，没有真实物理光线追踪。

按钮按下压低，圆环反光 12 秒一周，局部折射 7–9 秒缓慢变化。`prefers-reduced-motion: reduce` 停止环境动画与指针光影变化。控件支持原生键盘激活与可见焦点。760px 以下采用双列布局。

复用时可调背景、玻璃色、圆角、模糊与投影，但应保持光源方向一致；不要单独增大阴影却保留相反方向的高光。密集业务界面应减少模糊层数，并在目标设备验证性能。
