# UIM Skill 安装与分享

三个入口仅明确调用时执行：`UIM浏览`、`UIM自选`、`UIMID <ID或名字>`。Codex 的实际技能名为 `uim-browse`、`uim-auto`、`uim-id`，列表显示中文入口名。输入 `$uim` 搜索/选择技能是可靠入口；普通文本 `UIM` 是否显示自动联想取决于宿主，套件不伪造命令注册。安装后若列表未刷新，重新打开应用或新建对话。

## 安装

解压分享包，保留三个技能目录和 install.py 的相对位置。Windows 可双击「安装.cmd」安装，或双击「启动组件库.cmd」直接浏览，不安装 Skill 也可使用浏览站。需要 Python 3.9+ 且 python 命令可用：

```powershell
python install.py
```

默认安装到 CODEX_HOME/skills（未设置时为用户目录下 .codex/skills）。用 `--target "目标技能目录"` 指定其他兼容宿主；其他宿主是否执行显式调用策略需自行核对。不覆盖已有安装，也不修改全局 AGENTS.md。

## 使用

- `UIM浏览`：打开预构建的本地完整分类站，默认端口 5187，冲突时尝试到 5196；已有同快照服务复用。站点只监听本机，不需要 npm 或重新构建。
- `UIM自选 帮我做设备巡检记录筛选`：按交互结构选型，读取契约和代码后接入，不限目录里的演示业务。
- `UIMID date-range` 或 `UIMID 日期区间选择`：按 ID/名称解析；名字不唯一时列候选，不随意选。
- `UIMID uiverse-team-action-card 白色版`：按组件契约使用变体。

自动选型和按 ID 使用直接读取离线目录、哈希校验的源码包，不用启动网站。解包只进入新目录，Agent 审查依赖后再接入业务项目。源码包中的依赖版本用于复现参考，不强制升级宿主。

## 分发范围

本机项目仍保持完整。分享包保留 113 个目录入口及已有注册的独立源码包；没有独立包的页面明确标为页面参考。全息卡片个人收藏没有开放源码授权，分享站只展示说明页，不分发该实现和素材。原作许可不因打包而变化。部分演示引用的远程图片仍需要网络。

当前未部署在线站点；此版没有在线地址或自动联网下载，不宣称提供云端服务。后续可明确授权部署，再增加在线优先入口。

## 维护

源文件在仓库 skills/，共享帮助脚本位于 uim-browse/scripts/uim.py。浏览构建、目录、源码包只保存于生成产物和已安装目录，不把 dist、node_modules 或凭据打进 Git。

用户明确要求更新后才运行 `node scripts/package-uim-skills.mjs`。它从当前源码构建固定快照，导出目录和依赖版本；输出 artifacts/uim-skills，若已存在则拒绝覆盖。先归档旧产物，再生成、验证、分发并按用户授权替换已安装版本。平时修改业务项目不会自动升级 Skill。
