# UIModel 组件参考与迁移实施计划

用户已批准三方讨论方案，并要求未列举业务也能根据交互结构找到参考。

目标：网站和源码都提供相同的泛化方法、真实可运行示例、明确依赖与行为边界。沿用 React / Vite 和现有页面，无新增依赖、远端操作或全站重构。保留此前所有未提交修改。

- [x] 阅读入口：`docs/UI-REUSE.md` 作为公共方法来源；README、AGENTS、指南提供指针。按选择基数、层级、确认时机、条件依赖识别模式，示例不构成业务白名单。
- [x] 三个样板：搜索下拉、日期区间、前置条件。关闭源码/CSS依赖；前置条件显式表达 `{id,satisfied,content}`；日期翻页只浏览、快捷即确认，外部重置同步草稿。
- [x] 同源展示：新增组件引用清单、编译中的 TSX 样例、Markdown 阅读组件；网站展示真实文档、可复制源文件和完整用例。其他组件标识未完成独立复制验证。
- [x] 发现路径：指南优先公共方法，目录搜索支持结构词；搜索未命中也能回到选型方法和所有组件。
- [x] 验证：目录搜索回归、源码清单递归闭合和隔离 TypeScript 编译、原有测试/构建、网站交互检查；陌生 agent 分别仅凭源码和网站做不同业务迁移，把遗漏补回说明。
- [x] 收口：`docs/ACCEPTANCE.md` 记录实际证据、盲测结果和剩余边界；学习正文不累积测试流水账。

负责范围：主线程负责网站/目录/示例/集成验证；源码 subagent 负责样板解耦；文档 subagent 负责公共方法及组件契约。共享接口确认后接入，不交叉覆盖文件。
