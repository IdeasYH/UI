# FieldConfig：字段可见性与排列

ID：`feishu-field-config`。在组件总览搜索 ID，或从筛选示例工具栏的“字段配置”进入。样式按用户截图重建；记录全部为虚构演示，不修改飞书配置。

适合“已有字段集合 → 调整展示列、分组与顺序”的结构，不限于店铺、客户等业务名。它是视图配置，不是数据权限控制，也不会删除被隐藏字段的内容或已有筛选。

## 接口

`FieldConfig({ fields, onChange })` 是受控组件。`ConfigurableField` 扩展筛选字段定义，增加 `visible`、可选 `locked`、可选 `group`。字段 id 稳定，数组顺序就是列顺序；group 是平铺分组标签。锁定字段不能隐藏和移动，可重命名。宿主应传入分组成员连续排列的数组。

- 搜索按 label、pinyin、initials 有序模糊匹配，拼音需宿主提供；搜索时展开匹配字段所属组。
- 眼睛按钮立即切换显示；分组眼睛控制组内非锁定字段。折叠只隐藏配置列表中的子项，不改变表格列。
- 按住整行字段（名称、图标或空白区域）进行同组拖动排序，经过目标行的上／下半部分显示蓝色插入线，松开后按线的位置落位；眼睛和更多按钮保持点击操作；更多菜单的上移／下移提供键盘可访问的替代操作。跨组移动和固定列移动不生效。
- 更多菜单可重命名，拒绝空白与同名。改名清除旧拼音，宿主可重新提供准确读音。
- 新增支持文本、数字、日期，生成稳定 UUID，默认显示且无组；示例新增列的现有记录均显示未知“—”，不伪造数据。新字段的拼音可由宿主补齐。
- 配置即时回调，关闭不撤销。点击外部或 Escape 关闭，嵌套编辑优先取消。没有远程保存、删除字段、改类型或新建分组功能。

## 复制与组合

本体需要 `field-config.tsx`、`field-config.css`、`field-config-model.ts` 和 `condition-filter-model.ts`（共享搜索与字段类型）；依赖 React、React DOM、lucide-react，均为项目已有依赖。当前源码包还包含真实组合示例使用的筛选组件及 CSS。

`src/examples/condition-filter-example.tsx` 将同一字段状态交给配置面板和筛选器，表格由 visible 与数组顺序派生。字段隐藏不应自动取消筛选条件，因为“数据筛选”和“列显示”是不同状态。将它用于别的表格时保持稳定 ID、状态所有权与空值语义，替换字段数据、持久化和权限逻辑。

浮层在组件内定位，列表最多 430px 后滚动。复制到裁切容器或窗口边缘时由宿主处理浮层定位；字段权限和服务端校验不能依靠 hidden 或 locked 实现。
